# 分流标签

工程技能使用五种标准分流角色。本文件将这些角色映射到本仓库 issue 跟踪系统实际使用的标签名称。

| mattpocock/skills 中的角色 | 本仓库的标签     | 含义                             |
| -------------------------- | ---------------- | -------------------------------- |
| `needs-triage`             | `待分流`         | 需要维护者评估此 issue           |
| `needs-info`               | `待补充信息`     | 等待报告者提供更多信息           |
| `ready-for-agent`          | `可由智能体处理` | 规格明确，可以交由智能体自主处理 |
| `ready-for-human`          | `待人工处理`     | 需要人工实现                     |
| `wontfix`                  | `不予处理`       | 不会处理此 issue                 |

技能提到某个分流角色时（例如“应用适合智能体处理的标签”），请使用本表对应的标签名称。

如需调整实际使用的标签名称，请编辑“本仓库的标签”这一列。
