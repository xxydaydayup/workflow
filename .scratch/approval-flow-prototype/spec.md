# 审批流设计器 MVP 原型

## 目标

快速验证用户能否用少量基础节点构建审批流程，并将画布状态转换为 Camunda JSON→XML 接口需要的 `ProcessDefinitionDTO`。当前不接入真实后端。

## 决策

- 流程编辑状态由 React Flow 管理；编辑态使用 `position`、`data` 等结构。提交前由适配逻辑转换为后端 DTO，不能把 React Flow 原始 state 当请求体。
- 首版只展示开始事件、用户任务、排他网关、结束事件。
- 原型页面提供画布编辑、步骤编排、结构清单三种布局，使用 `/designer?variant=canvas|steps|structure` 切换。
- 节点名称、用户任务处理人和排他网关出边条件写入 DTO；坐标映射为整数 `x`、`y`。
- 本地原型只预览和复制请求 JSON，暂不调用后端、部署流程或持久化草稿。
- 前端编辑模型可以包含未完成内容；提交/部署前再由前后端进行完整性校验。

## 已知范围

当前 JSON Schema 校验字段和对象形状，不覆盖重复节点 ID、连线引用存在性等跨节点语义约束。原型使用示例流程展示常见直线路径与排他分支。
