# 04: 实现三栏流程设计器

Type: task
Blocked by: None
Status: resolved

**What to build:** 让流程设计者在一个业务友好的三栏编辑器中完成立项审批业务模型。左侧提供可拖入的业务节点库，中间画布支持放置、移动节点以及创建和调整连线，点击节点或连线后在右侧属性面板编辑名称和业务信息。编辑结果能生成[业务模型契约](../../../docs/examples/立项申请/project_approval_json.md)规定的 `project_approval_json`。

- [x] 节点库只显示当前业务流程支持的节点；开始和结束节点保持唯一，申请填写与审批使用清楚的业务名称。
- [x] 可将节点从节点库拖入画布，也可通过节点库点击添加；新节点添加后可在画布移动。
- [x] 可从节点连接点创建连线、选中连线编辑其业务含义，并拖动连线端点调整目标节点。
- [x] 选中节点时右侧显示并编辑节点业务属性；选中连线时显示并编辑路径业务属性；不要求用户输入审批人员、流程变量或流程引擎配置。
- [x] 编辑器使用固定的立项申请表单与 ALL 会签约定，不提供表单 schema 编辑或会签规则选择。
- [x] 编辑状态仅保留在当前页面；提供从编辑状态生成符合业务模型契约的 JSON 能力，不依赖草稿保存接口。

## Answer

已完成三栏立项审批流程设计器原型：左侧业务节点库支持点击或拖入添加，中间画布支持移动节点、创建和重连连线，右侧根据选中的节点或路径编辑名称与路径含义。申请填写步骤由完整流程的驳回目标识别，设计未完成时由开始节点后首个审批步骤暂时推断；用途信息不写入业务模型 JSON。会签以独立 countersign 类型输出并固定 approveMode: ALL。可预览和下载 project_approval_json；没有草稿、编译或发布接口时不调用后端。

验证：pnpm typecheck、pnpm test（34 项）、pnpm lint、pnpm build 全部通过；agent-browser 验证默认流程检查通过、节点面板、连线属性与模型 JSON 内容。构建保留现有超过 500 KB 的 bundle 提示。
