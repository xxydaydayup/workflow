# 04: 检查通用流程并定位问题

Type: task
Blocked by: 03
Status: 已完成

## What to build

让流程设计者在编译或发布前检查当前业务模型，并能从问题列表跳到对应节点或路径。规则服务于本项目当前支持的通用审批流程和节点契约，允许显式标记的驳回路径回流，同时阻止没有驳回语义的普通连线形成循环。

- [x] 检查开始/结束节点约束、节点和路径引用、重复/自连，以及每个流程节点从开始可达并能到达结束。
- [x] 检查条件分支的通过/驳回路径语义；不强制立项专属拓扑。
- [x] 允许 `branch: reject` 表达的打回回流；拒绝未标记普通路径构成的环。
- [x] 检查服务节点固定地址 URL 格式及会签 `passRate` 范围；不封闭 `approveMode` 值集合。
- [x] 检查结果可定位到问题节点或连线，且随当前模型更新。
- [x] 浏览器确认默认模型带有明确的 reject 回流且检查通过。模型级既有检查覆盖未标记普通环及问题定位；本轮再次在正式 `/designer` 触发检查并看到检查通过。

## Answer

本轮按最新 `/bpmn/spec` 补齐审批、会签、服务和条件节点出边的 `pass` / `reject` 标记，并允许已标记的拒绝回流；条件节点的 branch 仍要求恰有一个直接审批/会签/服务上游。未满足约束时错误定位到 condition 节点。连线属性面板支持编辑 `conditionExpression`，且业务 JSON 保留该值。

通用模型检查和画布定位已实现；浏览器通过含 reject 回流的默认流程检查。普通环定位逻辑已由模型校验覆盖；尚未通过浏览器人为造环和定位交互。后端契约限制见 issue 01。
